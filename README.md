# Employee Performance Analysis Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze employee performance across different departments, job titles, education levels, age groups, and employee characteristics.

## Tools Used

* Power BI
* Power Query
* DAX
* Excel

## Key Analysis

* Overall employee performance
* Performance by department
* Performance by job title
* High-performing employees
* Performance by education level
* Performance across age groups
* Performance by gender
* Employee tenure and performance

## Dashboard Features

* Interactive slicers
* KPI cards
* Performance visualizations
* Department and job-title analysis
* High-performer analysis

## Project Status

This project is currently being improved and updated. The dashboard design and analysis may be refined in future versions.
